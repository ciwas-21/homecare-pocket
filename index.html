🚑 有生命危險

先撥 119，再依單位規定通知督導與家屬。

☎️ 撥打 119

👩‍💼 非立即生命危險

先確保現場安全，記錄發生的時間與狀況，再聯絡督導依指示處理。

🤕 個案跌倒
口訣：先別扶、看反應、看傷勢、再通報

簡單處理步驟

  1. 先不要急著扶起來。
  2. 確認個案是否清醒、能不能正常說話。
  3. 觀察頭部、四肢是否有疼痛、出血或明顯變形。
  4. 若沒有明顯傷勢，依單位照護流程協助後續處理。
  5. 記錄跌倒時間、地點與當時情況，通知督導。
🚨 立即求助：
叫不醒、頭部重擊、大量出血、呼吸異常、劇烈疼痛或疑似骨折時，應立即尋求緊急醫療協助。
😵 昏倒／叫不醒
口訣：叫、看、求救
  1. 呼叫個案並確認是否有反應。
  2. 觀察是否有正常呼吸。
  3. 立即尋求協助並依緊急救護指示處理。
  4. 通知督導及家屬。
☎️ 撥打 119
🫁 呼吸困難
口訣：坐好、鬆衣、看呼吸、快求救
  1. 停止活動，讓個案保持較舒服且利於呼吸的姿勢。
  2. 鬆開過緊的衣物。
  3. 觀察意識、呼吸與嘴唇顏色。
  4. 依個案既有照護計畫及單位規定處理。
🚨 若嚴重喘不過氣、意識改變、嘴唇發紫或情況快速惡化，立即求助。
☎️ 撥打 119
🩸 大量出血
口訣：戴手套、直接壓、快求救
  1. 先做好自身防護，避免直接接觸血液。
  2. 使用乾淨敷料直接加壓傷口。
  3. 持續觀察個案意識與狀況。
  4. 大量出血或無法控制時立即求助。
☎️ 撥打 119
🌡️ 發燒
口訣：量體溫、補水分、擦乾換衣、持續觀察
  1. 量體溫並記錄時間與數值。
  2. 讓個案休息，依照照護計畫適量補充水分。
  3. 若出汗，協助擦乾並換上乾爽衣物。
  4. 持續觀察精神、呼吸與其他症狀。
  5. 通知督導及家屬，依單位流程處理。
🚨 若出現呼吸困難、意識異常、抽搐或其他明顯危急症狀，立即尋求緊急醫療協助。
